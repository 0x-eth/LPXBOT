4. Four older P04 governance tests treated new P04-06 files as changes to their earlier acceptance ranges. Their future-directory exclusions were extended; P04-06 adds its own fixed-baseline assertion.
5. Lint/typecheck found an implicit internal-operation projection plus narrow test fixture types. The projection is now an explicit public-field allowlist and the canonical fixture types are declared.
6. Gitleaks recognized Anvil's public development key as a generic key in two auto-sync commits. The exact file plus exact Anvil prefix is allowlisted with an AND condition; a repeat full-history scan found zero leaks.
