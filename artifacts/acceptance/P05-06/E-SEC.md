# P05-06 E-SEC

The self-digesting `p05-local-swap-execution-v2` Registry is independent from BSC. It fixes non-forked Anvil chainId 31337, `productionInheritance=false`, service fee 0 bps, two exact TestOnly token code identities, exact adapter/Permit2/router code identities, WalletHelperV1 runtime template, selectors, amount/block/age bounds, and rollback version `p05-local-swap-execution-disabled-v1`. Local signatures and broadcasts are open; testnet and production are structurally closed.

Immediately before Permit2 signing and before every step signature, the isolated Signer reauthorizes the durable plan and current chain facts: plan/quote/Registry digest and version, deadline/block range, wallet owner, active P05-05 binding, Helper owner/runtime hash/adapter/Permit2, token and component code hashes, step ordinal/nonce/fencing token, target/value/calldata digest, semantic digest, fee cap, and active transaction generation. Permit2 additionally rechecks exact token, Helper spender, amount, expiration, nonce, domain separator, signature deadline, and returned signature digest.

Ingress tests reject `target`, `router`, `spender`, `selector`, `calldata`, amount, and fee injection. Contract/domain tests reject changed calldata and semantic-changing or non-increasing replacements. Permit2 tests reject wrong nonce, stale expiration, domain mismatch, wrong returned digest, malformed signature, and unknown fields. Quote and plan tests reject stale/expired/changed quote, wrong minOut/deadline, wallet/Helper/Registry/code-hash mismatch, and arbitrary routes.

Foundry has 21 passing tests, including 256 fuzz cases and 128,000 invariant calls. It proves owner-only and replay protection, exact allowance cleanup, minOut/refund/dust invariants, malicious adapter fake-output rejection, false-return and fee-on-transfer token rejection, safe no-return and USDT-style approval handling, and callback reentrancy rejection. No BSC testnet/mainnet execution allowlist, public signer route, production broadcast route, or nonzero service fee was introduced.
