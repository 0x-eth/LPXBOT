# ADR-0002：分离市场数据面与交易执行面

- 状态：已接受
- 日期：2026-08-13

## 背景

市场读取、指标计算和 SSE 流量具有高吞吐、可降级特征；资金操作要求有界资源、最终性判断、幂等恢复和独立审计。让两类工作共享队列、RPC 配额或数据库权限会使数据流量影响交易确认，并可能让未确认市场数据直接触发资金动作。

## 决策

市场数据面负责只读链索引、指标、排行和事件流。交易执行面只接收经过鉴权的 command，生成不可变 execution plan，并依次模拟、签名、广播、确认和对账。两个平面使用不同 worker 队列、RPC 限额和数据库账号；执行面只读取版本化且达到所需最终性的市场快照。

## 结果

- 市场数据陈旧或过载时降级为只读告警，不自动转化为资金动作。
- 执行面的容量、权限、告警和恢复可独立验证，避免被热门池或聊天流量耗尽。
- 跨平面契约必须包含数据版本、区块高度、最终性和观察时间，便于审计与重放。
